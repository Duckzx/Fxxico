## 2026-08-13 - Focus Management in Animated Drawers & Accessible Custom Triggers
**Learning:** Animated drawers/drawers with sliding CSS transitions can lead to focus failure if focused immediately when the open action is triggered. Adding a 100ms-300ms setTimeout delay ensures the elements are fully paintable and interactive before calling `.focus()`. Also, styling global focus indicators via `:focus-visible` using a consistent shadow/color palette design preserves identity without native browser outline clutter. Custom trigger controls like labels for hidden inputs require explicit ARIA roles, tabindex, and Space/Enter key handlers for full keyboard navigation support.
**Action:** Always introduce dynamic timeout delays when managing focus inside transitions and explicitly bind Enter/Space triggers for hidden control labels using roles and tabindexes.
