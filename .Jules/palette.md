## 2024-05-27 - GitHub Header Anchors with Emojis
**Learning:** In GitHub Flavored Markdown (GFM), when a header starts with an emoji, the generated anchor slug includes a leading hyphen (e.g., `## 👤 Sobre mim` becomes `#-sobre-mim`). Removing this hyphen breaks the link.
**Action:** Always verify header anchor slugs when headers contain emojis or special characters. Use a leading hyphen in the link if the emoji is at the start of the header.
