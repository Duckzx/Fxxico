## 2026-06-15 - Focus Management in Transitioning Drawers & Key Mapping for Hidden Input Labels
**Learning:** Standard programmatic `.focus()` calls on elements inside CSS-transitioned container elements (like animated sidebar drawers) often fail if executed immediately upon opening, because the browser may not consider the element interactable or fully visible until the transition starts or finishes. Introducing a slight `setTimeout` delay of 100ms-300ms is necessary to ensure focus lands successfully. Additionally, wrapper elements like `<label>` wrapping `display:none` files inputs are excluded from keyboard tab orders by default; making them fully accessible requires explicitly setting `tabindex="0"`, `role="button"`, and mapping Enter/Space key events to programmatically click the input.
**Action:** Always wrap side drawer focus shifts in a brief `setTimeout` (e.g., 150ms) to ensure CSS transitions don't block element focus. Explicitly assign `tabindex`, `role`, and keydown handlers to customized wrapper components like file-upload labels to guarantee screen readers and keyboard-only users can navigate and trigger them.
